Track画面（トラックエディタ）は、ピアノロール形式で各トラックのノート（音符）を入力・編集・確認するための画面です。 コード伴奏やドラムパターンに合わせたメロディの作成、フレーズの細かな調整、リアルタイム演奏の録音データの編集を行うことができます。

3つのトラックと、main画面での演奏を保持しているJamトラックの、合計4つのトラックがあります。
- Track 1-3:
  - メロディや副旋律、ベースラインなどのフレーズを打ち込むためのトラックです。<br>設定された Loop（繰り返し）や Jump（ジャンプ）などの構成展開に連動して再生されます。
- Track Jam (Track 4):
  - メイン画面の鍵盤などでリアルタイム演奏・録音したデータが記録されるトラックです。<br>曲全体の通し（絶対時間）に沿って再生されます。

> 💡 **ポイント**
> 曲のフロー制御（Loop/Jump）に関して、Jamトラックは他のトラックとは別扱いになっており、
>「Configure Loop」で曲のフロー制御がデフォルト以外に場合には、
> Jamトラックとそれ以外の小節の位置関係が少々複雑です。
> 詳細は[「ConfigureLoop設定と小節位置」](playflow)を参照ください。


トラックごとに音量や音色の設定を保持できます。

- 一般的なピアノロールの編集作業が可能です 
  - 3段階のセルのサイズ指定（Small,Medium,Large）、黒鍵の非表示が可能です。
  - ステップ入力・ホールド入力・リアルタイム入力に対応しています。
  - ノートの移動・クオンタイズが可能です。
- 「Overlay」で別のトラックのノートを確認しながら編集できます。
- 「chroma」を有効にすることで、異なるオクターブのノートを重ねて表示することで、音の響きの確認に使えます。
- 「Undo」「Redo」によるやり直しと再実行
  - ノートの追加・移動・削除などの操作を間違えた場合、<br>Undo（取り消し）/ Redo（再実行）ボタンで即座に前の状態に戻すことができます。

# 画面構成と基本操作

## ピアノロール（グリッドエリア）

- ノートの入力・編集（「Pen」ツールを選択中）
  - グリッド上をタップまたはドラッグすると、指定したピッチ・長さにノート（音符）が配置されます。
  - ノートをタップすると消去します（「EraseNote」ツールでも可能）
  - ノートをドラッグすると移動できます（「Move」ツールでも可能）
  - ノートの末尾付近をドラッグするとノートの長さを調整できます（「Stretch」ツールでも可能）
  - <iframe width="250" height="444" src="https://www.youtube.com/embed/7EhSSyPRq70" frameborder="0" allowfullscreen></iframe>

- 画面のスクロール
  - グリッド上を2本指（条件によっては1本指でも）で表示位置をスクロールできます
  - 小節番号の部分であれば、1本指で左右にスクロールできます
  - 鍵盤の上の左「<」右「>」の矢印で移動も可能。「◎」でカーソル位置までジャンプします
  - <iframe width="250" height="444" src="https://www.youtube.com/embed/LoMWsjrtwsk" frameborder="0" allowfullscreen></iframe>

- カーソル位置の変更
  - 小節番号の部分をタップすると、セルのグリッドに合わせた位置にカーソルを設定できます
  - カーソル位置から再生やステップ入力が開始します
  - <iframe width="250" height="444" src="https://www.youtube.com/embed/pzljRwludjM" frameborder="0" allowfullscreen></iframe>

- 選択（「Sel」ツールを選択中）
  - 小節番号の部分をドラッグすることで縦方向にセルを選択でき、その中に存在するノートを選択できます
  - グリッド上で矩形でドラッグすることで、矩形内のノートを選択できます
  - 選択したノートは自動的にクリップボードにコピーされます
  - 選択後に表示されるダイアログで、選択したノートに対して以下の差操作が可能
    - 削除（縦方向に選択している場合のみ使用可能。選択した範囲を削除し左詰めします）
    - クリア(ノートを消すだけ。左詰めはしません)
    - セル単位・オクターブ単位・小節単位でノートの移動が可能
    - クオンタイズ
      - Quantizeのボタンを長押しで詳細設定が可能です
  - <iframe width="250" height="444" src="https://www.youtube.com/embed/K_b1Ht9mtXw" frameborder="0" allowfullscreen></iframe>

- 参照（「Ref」ツールを選択中）
  - 同じフレーズやサビのリズムを何回もコピー＆ペーストせずに、特定の小節を参照することができます。参照先のパターンを変更すると、参照元も自動的に変更されます。
  - 参照は小節単位の動作となります。小節の半分単位での参照はできません。
  1. Refを選択している状態で、参照を設定したい小節を複数選択します
  2. Refを押して、参照設定ダイアログを開きます
  3. 参照先の小節を指定します
  4. LimitEndPositionを有効にした場合には、参照する小節の範囲を指定します。
    - ![ref_with_endpos](../assets/images/chord/chord_ref_with_endpos.jpg)
  - 例えば、小節を4つ選択している状態で、参照先を1-1に指定しているとします。
    - LimitEndPositionが無効の場合、
      - 1-1, 1-2, 1-3, 1-4 が参照先として設定されます。
    - LimitEndPositionを有効の場合、
      - LimitEndPositionに1-2を指定すると、<br>1-1, 1-2, 1-1, 1-2 が参照先として設定されます。
    - <iframe width="250" height="444" src="https://www.youtube.com/embed/gLMd-Joahyc" frameborder="0" allowfullscreen></iframe>


## ツールバー（各種編集モード）

![tools](../assets/images/track/track_tools.png)


画面下部のツールエリアの文字の選択で編集モードを切り替えます。

### 1. Pen ツール

ノートの直接入力や編集を行う基本的なツールです。

| ツール表示 | 機能概要 | 主な操作方法と挙動 |
| :--- | :--- | :--- |
| **Pen** | ノートの<br>入力と編集 | ・**空きセルをタップ**: 指定クオンタイズの長さでノートを新規入力（プレビュー音再生）<br>・**既存ノートをタップ**: 該当ノートを消去<br>・**既存ノートを長押しドラッグ**: ノートの位置移動および長さ伸縮 |

### 2. Stretch / Move / Split ツール

既存ノートの伸縮・移動・分割を行うグループです。  
ボタンをタップするごとにモードが切り替わります。

| ツール表示 | 機能概要 | 主な操作方法と挙動 |
| :--- | :--- | :--- |
| **Stretch** | 伸縮<br>結合 | ・**ノート右端をドラッグ**: ノートの開始位置または終了位置を伸縮<br>・**ノートをダブルタップ**: 同じ音高で隣接・連続するノート群を1つに結合（マージ） |
| **Move** | 移動 | ・**ノートをドラッグ**: 時間軸（横）および音高（縦）へ移動（移動中にピッチ音をプレビュー再生） |
| **Split** | 分割 | ・**ノート上のセル位置をタップ**: 1つのノートをタップしたグリッド位置で2つに分割 |

### 3. Sel / SelAll ツール

複数ノートの選択を行うグループです。  
ボタンをタップするごとにモードが切り替わります。

| ツール表示 | 機能概要 | 主な操作方法と挙動 |
| :--- | :--- | :--- |
| **Sel** | 範囲選択 | ・**ドラッグ**: 囲んだ範囲内のノートを選択<br>・**ルーラー部ドラッグ**: 特定時間範囲の全音高ノートを一括（Column）選択 |
| **SelAll** | トラック全選択 | ・**タップ**: 現在のトラックにあるすべての表示ノートを一括選択<br>※選択されたノート群はまとめてドラッグ移動やコピーが可能 |

### 4. Erase / Delete ツール

ノートやマス、小節の消去・削除を行うグループです。  
ボタンをタップするごとに7種類のモードが順次切り替わります。

| ツール表示 | 機能概要 | 主な操作方法と挙動 |
| :--- | :--- | :--- |
| **EraseNote** | ノート単位の消去 | ・**ノートをタップ**: 該当ノート全体を削除（時間は変化なし） |
| **EraseCell** | セル（マス）単位の消去 | ・**ノート上のセルをタップ**: 該当マス（1セル分）のみ切り抜いて削除（ノートの中抜き・分割消去） |
| **EraseBar** | 1小節単位の消去 | ・**小節をタップ**: タップした小節（1小節＝96 Tick分）に含まれる全ノートを削除 |
| **DeleteNote** | ノート時間範囲削除＆詰め | ・**ノートをタップ**: 該当ノートが占める時間幅（全音高）を削除し、それ以降のノートを左へ詰める |
| **DeleteCell** | セル時間範囲削除＆詰め | ・**セルをタップ**: 該当セル1マス分の時間幅（全音高）を削除し、それ以降のノートを左へ詰める |
| **DeleteBar** | 小節削除＆詰め | ・**小節をタップ**: 該当小節（1小節分）を丸ごと削除し、以降の小節および参照関係を1小節分左へ詰める |
| **EraseAll** | トラック全消去 | ・**タップ**: 現在のトラックのノートをすべて一括削除（確認ダイアログを表示） |

### 5. Insert ツール

空白の時間（小節やセル）を挿入するグループです。  
ボタンをタップするごとにモードが切り替わります。

| ツール表示 | 機能概要 | 主な操作方法と挙動 |
| :--- | :--- | :--- |
| **InsertBar** | 1小節分の時間挿入 | ・**小節をタップ**: タップ位置に1小節分の空白時間を挿入し、以降のノートおよび参照を右へシフト |
| **InsertCell** | 1セル分の時間挿入 | ・**セルをタップ**: タップ位置に1マス分の空白時間を挿入し、以降のノートを右へシフト |

### 6. Ref ツール

他の小節の演奏データを参照（リファレンス）指定するツールです。

| ツール表示 | 機能概要 | 主な操作方法と挙動 |
| :--- | :--- | :--- |
| **Ref** | 小節参照（リファレンス）設定 | ・**小節を選択してタップ**: 他の小節の演奏データを参照として割り当て、あるいは既存参照を解除 |

## 鍵盤からの入力

鍵盤下の右のボタンは鍵盤からの入力モードを指定します。

![input_mode](../assets/images/track/track_step_hold_realtime.png)

### 1. `NONE` (ノーマル / 試奏)

**操作**: 
- 鍵盤を押すと音色が鳴りますが、トラックには一切書き込まれません。  

**用途**: 
- 音色のニュアンス確認やフレーズの練習に最適です。

---

| 項目 | 内容 |
| :--- | :--- |
| **機能概要** | 記録を行わない演奏・試奏モード |
| **音価の決定** | 記録されません（音が鳴るのみ） |
| **カーソル移動** | 移動しません |
| **主な用途** | ・メロディやコードの試奏・音色確認を行いたいとき<br>・画面グリッド上の手動タップ・ドラッグ編集に専念したいとき |

---

### 2. `STEP` (ステップ入力)

**操作**:  
  1. クオンタイズ（例: `16` や `8`）を選択。
  2. トラック上の開始したい位置へカーソルを合わせる。
  3. 鍵盤を押すと、カーソル位置にその長さのノートが打ち込まれ、自動的にカーソルが次へ進みます。

**用途**: 
- 高速なフレーズやアルペジオなど、手動配置が面倒な定尺ノートの打ち込みに適しています。

---

| 項目 | 内容 |
| :--- | :--- |
| **機能概要** | 鍵盤を押すたびに定尺ノートを1音ずつ自動配置 |
| **音価の決定** | 設定されている**Quantization（クオンタイズ）**の単位長（16分、8分など）で固定 |
| **カーソル移動** | ノート入力後、**1ステップ分右へ自動進行** |
| **主な用途** | ・再生を止めた状態で、楽譜通りに一定リズムのノートを1音ずつ正確に入力したいとき（ステップレコーディング） |

---

### 3. `HOLD` (ホールド入力)

**操作**:
  1. トラック上の開始位置にカーソルを合わせる。
  2. 鍵盤を長めに押すと長いノート（2分音符や全音符など）、短くタップすると短いノート（16分音符など）が配置されます。
  3. 離すとカーソルがそのノートの直後へ移動し、連続して入力が可能です。

**用途**:
- 伸ばす音と短い音の混ざったメロディやコード進行を手動でテンポよく入力するのに便利です。

---

| 項目 | 内容 |
| :--- | :--- |
| **機能概要** | 鍵盤を**押している時間**に応じてノートの長さを決定 |
| **音価の決定** | 鍵盤を押し込んでから離すまでの時間に合わせ、**クオンタイズ単位に丸めた長さ**で動的生成 |
| **カーソル移動** | ノート入力後、**そのノートの末尾位置へ自動進行** |
| **主な用途** | ・8分音符や全音符など、様々な長さの音符を鍵盤の押下時間で感覚的に入力したいとき |

---


### 4. `REALTIME` (リアルタイム録音)

**操作**:
  1. モードを `REALTIME` に切り替え、再生ボタン（Play）を押す。
  2. 楽曲の再生に合わせて鍵盤を演奏すると、押したタイミングと長さでノートがトラック上へリアルタイム書き込みされます。

**用途**:
- 演奏のフィーリングやリズム感をそのまま曲に反映させたい場合に活用できます。

---

| 項目 | 内容 |
| :--- | :--- |
| **機能概要** | 曲の再生中に鍵盤の演奏をそのままリアルタイム記録 |
| **音価の決定** | 実際に鍵盤を押して離したリアルタイムの演奏時間 |
| **カーソル移動** | 再生の進行に合わせて**リアルタイム追従** |
| **主な用途** | ・再生ボタンを押し、曲に合わせて鍵盤を演奏しながら直感的にレコーディングしたいとき |

## 再生コントロールパネル

![play](../assets/images/track/track_play.png)

main画面と同じく、演奏を制御するためのUIです。

Track,Chord,Drum,MetronomeのON/OFFを切り替えることができます。  
T:ON/OFF の長押しで個別のトラックのON/OFFを切り替えられます。

左側には再生中の小節位置と、その位置に対応するChord画面に設定されているコードを表示します。

# ❓ よくある質問（Q&A）

#### Q1. ノートを入力したのに再生時に音が鳴りません。

以下の点をご確認ください。

1. 画面下部の T:ON ボタンが有効（ON）になっているか確認してください。
2. T:ON ボタンを長押しして、対象トラックにチェックが入っているか確認してください
3. トラックの音量（Volume）が 0 になっていないか確認してください。

#### Q2. Chromaボタンを押すと薄い枠でノートが表示されますが、タップしても削除・編集できません。

薄い枠で表示されているノートは、「別のオクターブで鳴っている同じ音名のノート」 です。編集したい場合は、ピアノロールを上下にスクロールして、実体のあるオクターブ位置まで移動してから編集を行ってください。

#### Q3. 小節番号の文字が「赤色」で表示されるのはなぜですか？

「Loop（繰り返し）」や「Jump（ジャンプ）」などの曲構成設定が反映された小節位置 を示しています。
- Track 1〜3: 常に赤色表示（構成に追従）となります。
- Track Jam: 小節番号部分をタップすることで、通しの絶対小節位置（黒色）と赤色表示を交互に切り替えられます。


#### Q4. 手動でカーソル位置を動かしたのに、下の小節番号やコード表示が変わりません。

ピアノロール上やスクラブバーでカーソルを動かすと、リアルタイムで下部の小節番号とコード名が追従して更新されます。更新されない場合は、画面が再生中になっていないか確認し、停止中にカーソルをタップし直してください。

#### Q5. スムーズに再生されません

Overlayで他のトラックを表示していると再生がつまずいたり一瞬停止したりなどスムーズに再生されない場合があります。

OverlayをNoneに設定していただくか、Track画面を表示している状態でハンバーガーメニューのTrackをタップして、
「Play with Overlay On」を OFF にし、再生時のOverlay表示が無効になる設定を試してみてください。

![Play with Overlay On](../assets/images/track/track_play_with_overlay.png)
