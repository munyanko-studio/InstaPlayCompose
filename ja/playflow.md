# 概要

InstaPlayでは、**「Jamトラック」**と**「その他のトラック（Track 1〜3 / Chord / Drum）」**で小節位置の扱いが異なります。

「ConfigureLoop（ループ・ジャンプ設定）」を使用している場合、**Jamトラックの小節位置と、その他のトラックの小節位置に表記や演奏位置のズレが生じる仕組み**になっています。

---

## 1. トラックごとの再生方式の違い

###  ① Jamトラック（Track 4）
- **特徴**: 曲の先頭（`01-1`）から最後まで、**ジャンプやループの影響を受けず一続き（リニア）に再生・録音**されます。
- **再生位置**: 曲全体の「通し時間（絶対的な小節位置）」に基づきます。

###  ② その他のトラック（Track 1〜3 / Chord / Drum）
- **特徴**: **「ConfigureLoop」で設定したループやジャンプ、開始位置変更に従って再生**されます。
- **再生位置**: ループやジャンプが反映された「バックトラック上の小節位置」に基づきます。

---

## 2. 小節位置が「ずれ」て表示・演奏される具体例

ConfigureLoopの設定内容によって、以下のようにJamトラックと他トラックの位置関係が変化します。

### 例1：再生開始位置を `05-1` に設定した場合
- **Jamトラック**: 曲の先頭 `01-1` から順番にカウントが進みます。
- **他トラック**: ConfigureLoopで設定された `05-1` の位置のパターンが曲の最初（Jamトラックの `01-1`）と同時に演奏されます。

### 例2：サビの4小節間をループ再生（繰り返し）設定した場合
- **Jamトラック**: 演奏中も `01-1` ➔ `02-1` ➔ `03-1` ➔ `04-1` ➔ `05-1` ➔ `06-1` ... と止まらずに進みます。
- **他トラック**: ループ区間に達すると、`01-1` ➔ `02-1` ➔ `03-1` ➔ `04-1` ➔（ループ）➔ `01-1` ➔ `02-1` ... と元の小節に戻って繰り返されます。

> 💡 **ポイント**
> Jamトラックに演奏を録音する際、バックトラック（他トラック）が繰り返し再生されていても、Jamトラックには「最初から最後まで通して演奏したフレーズ」がそのまま記録されます。

---

## 3. 画面下の「小節番号表示」の見方

画面下部（Playボタンの左側）に表示される小節番号は、モードやトラックによって色や数値が変わります。

| 画面 / トラック | 表示色 | 表示される小節番号の意味 |
| :--- | :--- | :--- |
| **Main画面 / TrackJam** | **通常色（黒/白）** | **通し番号（絶対位置）**<br>曲の先頭からの経過小節（elapsedTicks） |
| **Main画面 / TrackJam** | **赤色** | **ジャンプ/ループ適用後の番号**<br>バックトラックが今演奏している小節（backingTick） |
| **Track 1 / 2 / 3** | **赤色** | **ジャンプ/ループ適用後の番号**<br>そのトラックが今演奏している小節（backingTick） |

### タップで表示の切り替えが可能！
Main画面およびTrackJam画面の下部にある小節番号（例: `01-1`）をタップすると、
**「通し番号（通常色）」** ⇄ **「ジャンプ/ループ適用後の番号（赤色）」** をワンタップで簡単に切り替えることができます。停止中にタップしても表示が切り替わります。

## 4. ❓ Q&A（よくある質問）

#### Q1. Jamトラックを録音中、他トラックと小節番号が違っていて不安です。故障ですか？
**故障ではありません。正常な動作です。**
ConfigureLoopでジャンプや開始位置の変更、ループ設定を行っている場合、バックトラック（Track 1〜3/Chord/Drum）は指定された区間を繰り替えしますが、Jamトラックはユーザーの演奏を曲全体として通しで記録するため、小節番号のカウントが分かれます。

#### Q2. Track 1〜3 画面で小節番号が「赤色」で表示されているのはなぜですか？
**ConfigureLoopの影響を受けるトラックであることを示すためです。**
Track 1〜3 はループやジャンプの設定によって再生位置が変化するため、現在バックトラックとして演奏されている小節番号であることを分かりやすく「赤色」で目立たせています。
