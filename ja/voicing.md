# 概要

OFF（固定基本形）の時には、すべてのコードを基本形（Root音を一番下にした密集配置）で鳴らします。コードが変わるたびに和音全体がそのまま平行移動するため、音高の跳躍が大きくなり、電子音特有の機械的な鳴り方になります。

ON（自動ヴォイスリーディング＆最適配置）の時には、コード進行の流れ（前後の文脈）を分析し、スムーズな声部導行（Voice Leading）・転回形の自動選択・音の濁り防止（ロー・インターバル・リミット対策） をリアルタイムに行い、人間が鍵盤や弦楽器で演奏しているような自然で美しい響きを生成します。

# アルゴリズム

VoicingがONの時、システムは和音を 「バス音（低音）」 と 「上声部（アンサンブル構成音）」 の2つに分離して処理します。

## ① スムーズな声部導行（Voice Leading Heuristic）

- 中心音高（アンカー）の保持
  - 直前に鳴っていたコードの上声部構成音の「平均ピッチ（中心点）」を記憶します。
- 最短オクターブの自動選択
  - 新しいコードの各音（C, E, G などのピッチクラス）について、直前の中心点に最も距離が近いオクターブを算出して配置します。これにより、同じ音が共通していれば同音保持し、構成音の変化も最小限の音程移動（ステップ移動）に抑えられ、自然な転回形（Inversion）が自動的に組み上げられます。
- 音域のスパイラル防止（クランプ処理）
  - コード進行によって音がどんどん高音域（または低音域）へ逃げてしまわないよう、中心点には適正な音域制限（標準モードでは C4/Middle C 周辺）がかけられています。

## ② 音の衝突・濁り防止（Anti-Clashing / Open Voicing 化）

- 2度音程の自動展開 
  - 上声部の中で半音または全音（1〜2半音差）の近接した音が重なると、鍵盤の押さえ方やストローク時に音が濁る原因になります。Voicing ON時は、近接した上側の音を自動的に1オクターブ引き上げてオープン・ヴォイシング（スプレッド配置）に補正します。

## ③ 3つの「楽器別ヴォイシング・モード」

設定されている楽器タイプ（InstrumentVoicing）に応じて、物理的な音域や楽器固有の奏法特性を再現します。


| モード | バス音の音域 | 上声部の中心音高 | 楽器特有の補正アルゴリズム |
| :--- | :--- | :--- | :--- |
| **NORMAL**<br>*(ピアノ/キーボード系)* | **C2 〜 B2**<br>(MIDI 36〜47) | **C4（Middle C）周辺** | 上声部で1度・2度のぶつかり（隣接音）がある場合、上の音を1オクターブ上に逃がして響きをクリアに保ちます。 |
| **GUITAR**<br>*(ギター系)* | **E2 〜 D3**<br>(MIDI 36/40〜50) | **D4 周辺** | ギターのローコード（オープンコード）の響きを再現するため、上声部に基音（ルート音/オクターブ4）が含まれていなければ自動補正追加。また、ストローク時の濁りを防ぐため2度音程をオクターブ上に逃がし、ハイフレットの上階（C6 / MIDI 84）を超えないよう調整します。 |
| **BASS**<br>*(ベース/低音系)* | **C1 〜 B1**<br>(MIDI 24〜35) | **F2 周辺** | ロー・インターバル・リミット（Low Interval Limit）対策を強化。低音域で短3度以下の狭い音程が重なると強いブーミー感・濁りが発生するため、3半音以下の近接音を自動的に1オクターブ上へシフトします。 |

# まとめ

Chord画面の **Voicing ON** は、単にコードを鳴らすだけでなく、
* **演奏者の手癖・スムーズな運指（鍵盤の転回形やギターの押さえ方）**
* **音楽理論に基づいた和音の音程分離（オープン/クローズド配置の最適化）**

をプログラマティックに計算し、打ち込み特有の「重苦しさ」や「唐突な跳躍」を排除したプロフェッショナルな和声の響きを作るアルゴリズムとなっています。

とはいえ、時には意図しない状況にはなると思うので、状況に応じてOFF/ONを使い分けてみてください。
